# 呼び出しの仕組み

どのバインディングも同じ C API を包んでいるため、呼び出しの動作はどの言語でも同じです。違うのは名前だけで、Python、Node.js、Rust、C では `convert`、C# では `Convert` です。

## 読みと文節

読みは入力された文字列で、ひらがなです。読みを変換すると文節に分かれます。各文節は読みの一部を受け持ち、良い順に並んだ候補を持っています。

| 文節 | 読み | 候補 |
|---|---|---|
| 1 | きょうは | 今日は、きょうは、教は、… |
| 2 | さむいですね | 寒いですね、さむいですね、サムいですね、… |

各文節の最初の候補をつなげたものが、Mozc の最良の変換「今日は寒いですね」です。候補には、Mozc による日本語の注記（例: カタカナ）が付くこともありますが、ほとんどの候補には付いていません。

## 文節の長さ

文節の区切りは Mozc が決めますが、長さを渡して指定することもできます。長さはバイト数や UTF-16 のコード単位ではなく Unicode の文字数で、文節ごとに 1 つずつ渡し、合計が読みの長さと一致する必要があります。長さ `[3, 5, 2]` で変換すると、ここではきものをぬぐ は ここで / はきものを / ぬぐ に区切られ、2 番目の文節の候補には「は着物を」と「履物を」の両方が並びます。

入力メソッドでユーザーが文節の区切りを動かすときは、新しい長さでもう一度変換します。

## 文脈

`context` は読みの直前の文で、たとえばユーザーがすでに送った文です。Mozc はこれを履歴として使うため、最初の文節を文の始まりではなく続きとして変換します。なければ空にしてください。

## 予測

`predict` は入力途中の読みの補完候補を返します。ありがと なら ありがとうございます、ありがとう などです。結果は文節に分かれず、1 つのリストで返ります。

## 学習

ユーザーが変換を送ったら、`learn` で学習させます。渡すのは、読み、各文節の長さ、各文節で選ばれたテキストです。同じ読みを次に変換するとき、選ばれたテキストが先頭に並びます。`learn` が受け付けるのは文節の候補にあるテキストだけで、それ以外があると何も学習せず false を返します。

`clear_learning` は学習した内容をすべて消します。`flush` は学習した内容をすぐにプロファイルへ書き込みます。閉じるときにも書き込まれます。

## プロファイル

プロファイルは、Mozc が学習した内容を保存するディレクトリです。存在しなければ作成され、ディレクトリを指定しなければ Mozc の既定の場所（Linux では `~/.mozc`）を使います。

Mozc はプロファイルディレクトリをプロセス単位で保持するため、1 つのプロセスで開くプロファイルは 1 つだけにしてください。同じプロファイルを閉じてから開き直すのは問題ありません。

incognito モードは何も学習せず、プロファイルにも触れません。記録すべきでない入力に使います。

## エラー

要求どおりに処理できなかった呼び出しは何も返しません（空のリスト、または false）。理由は `last_error` で、「the segment lengths do not add up to the reading's length」のような英語の文として取得できます。決まった文なので入力された文字列が含まれることはなく、ライブラリが読みや学習データをログに出すこともありません。

ライブラリを読み込めない場合、C API のバージョンが異なる場合、Mozc を起動できない場合は、開く処理が失敗します。言語によって、例外になるかエラー値が返るかが異なります。

## スレッド

1 つのハンドルは複数のスレッドから使え、呼び出しは順番に処理されます。

## ライブラリ

どのバインディングも同じネイティブライブラリ（`libmozc_ffi.so` または `mozc_ffi.dll`）を一度だけ読み込み、解放しません。

| | 探す場所 |
|---|---|
| Python | `library=`、`MOZC_FFI_LIBRARY`、モジュールと同じ場所（wheel はここに入れます）、システムのパス |
| C# | P/Invoke: パッケージの `runtimes/` にあるマシン用のもの、プログラムと同じ場所、システムのパス |
| Unity | パッケージに入っている Windows x64 または Linux x64 用のプラグイン |
| Node.js | `MOZC_FFI_LIBRARY`、`@mozc-ffi/<platform>-<arch>` パッケージ、システムのパス |
| Rust | `MOZC_FFI_LIBRARY`、実行ファイルと同じ場所、`download` フィーチャーが置いた場所、システムのパス |
| C | リンクしたもの |

ビルド済みのライブラリは、Linux x64 と arm64（glibc 2.28 以降）、Windows x64 に対応しています。Windows の DLL は C++ ランタイムを静的リンクしているので、Visual C++ 再頒布可能パッケージは不要です。
